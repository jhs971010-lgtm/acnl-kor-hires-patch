# 튀어나와요 동물의 숲 amiibo+ 한국판 — 800×240 패치

**v0.9 · 공개 베타**

3D 슬라이더를 내리면 상단 화면을 800×240 2D로 출력하고, 올리면 기존 400×240 3D 출력으로 자동 전환하는 패치입니다. 대화창·로고 등 상단 UI의 출력 폭도 함께 전환합니다.

## 지원 대상

| 항목 | 내용 |
|---|---|
| 게임 | 튀어나와요 동물의 숲 amiibo+ 한국판 |
| 타이틀 ID | `0004000000199000` |
| 실기 확인 기종 | New Nintendo 3DS XL |
| 슬라이더 OFF | 상단 800×240 2D |
| 슬라이더 ON | 기존 상단 400×240 3D, 한쪽 눈 기준 |
| 하단 화면 | 기존 표시 해상도와 UI 영역 유지 |

뉴 3DS XL의 테스트 환경에서 게임 진행, 상단 UI, 화면 전환과 2D/3D 자동 전환이 정상 작동하는 것을 확인했습니다. 다른 기종·지역판·실행파일 및 업데이트 조합, 장시간 플레이와 모든 특수 장면은 검증하지 않았습니다. 타이틀 ID가 같아도 모든 버전의 호환성을 보장하지는 않습니다.

이 버전은 800×240 패치입니다. 480줄 렌더링 및 SSAA 기능은 포함하지 않습니다.

## 다운로드 및 설치

이 저장소의 **Releases**에서 `ACNL_KR_800x240_v0.9.zip`을 내려받으세요. GitHub가 자동 생성하는 `Source code` ZIP과 구분해 주세요.

Luma3DS에서 게임 패치를 사용할 수 있는 환경이 필요합니다. 설치 전 세이브와 기존 패치 파일을 백업해 주세요.

1. 게임을 완전히 종료합니다.
2. 다운로드한 ZIP을 풀고 `luma` 폴더를 SD 카드 최상위에 복사합니다.
3. 최종 파일 위치가 아래와 같은지 확인합니다.

   `SD:/luma/titles/0004000000199000/code.ips`

4. 같은 위치에 기존 `code.ips`가 있으면 백업한 뒤 교체합니다.
5. Luma3DS의 **Enable game patching** 설정을 켭니다.
6. 3D 슬라이더를 내린 상태로 게임을 실행합니다.
7. 게임 화면에서 슬라이더를 올렸다 내려 2D/3D 전환을 확인합니다.

다른 실행파일 패치와 함께 사용하는 조합은 미검증입니다. 게임 실행 중 파일만 교체하면 새 패치가 반영되지 않으므로, 반드시 게임을 종료한 뒤 다시 실행하세요.

## 해제 및 복원

게임을 종료하고 위 경로의 `code.ips`를 해당 타이틀 폴더 밖으로 옮긴 뒤 다시 실행하면 패치가 해제됩니다. 기존 패치로 돌아가려면 백업한 파일을 복원하세요.

## 알려진 제한

- 공개 베타이며 모든 장면과 기종에서의 안정성을 보장하지 않습니다.
- 3D 모드의 해상도는 기존과 같습니다. 한쪽 눈당 800×240으로 출력하는 기능은 아닙니다.
- 2D/3D 전환 순간 잠깐 화면이 갈라지거나 이전 프레임이 보일 수 있습니다. 계속 남는 화면 깨짐과는 구분해 제보해 주세요.
- 화면이 계속 깨지거나 게임이 멈추면 패치를 해제하고 같은 구간을 다시 확인해 주세요.

## 문제 제보

문제가 발생하면 **Issues**에 아래 내용을 알려주세요.

- 패치 버전
- 기기 모델 및 Luma3DS 버전
- 게임 지역판 및 업데이트 버전
- 함께 사용하는 패치
- 발생 장소와 재현 순서
- 발생 당시 슬라이더 위치
- 패치를 해제해도 같은 문제가 발생하는지
- 가능하면 사진 또는 오류 화면

ROM, 원본 실행파일과 메모리 덤프는 공개 이슈에 첨부하지 마세요.
